# AGENTS.md (Global)

IMPORTANT: These are my common development preferences and guidelines. You **MUST** follow them when working on the projects.

## Workflow

- For any feature/bugfix request, **ALWAYS** adhere to this flow:
    - Perform a thorough research, inspect the codebase and relevant files
    - Having gathered all the required information, write a detailed step-by-step *PLAN*
    - Finally get explicit user's approval before starting to implement the plan. If user objects, continue refining the plan according to user's comments until approval
    - These tasks do not require plan:
        - Research/explanation
        - Commiting the changes
- **NEVER** make any assumptions: if unclear, STOP and ask for clarification/confirmation
- **NEVER** implement fallback/workarounds: if a task can't be implemented as intended, STOP and explain the problem

## Codestyle

- **NEVER** use non-ASCII typographic/presentation symbols (no smart quotes, em-dashes, arrows like -> rendered as →, etc.). Use plain ASCII equivalents.

## Development Tools

- **ALWAYS** use `gh` CLI for interacting with Github
